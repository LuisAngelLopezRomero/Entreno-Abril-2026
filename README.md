# Entreno Abril 2026

Miniapp personal para registrar dieta, entrenamiento y rachas.

## Qué incluye

- Dieta completa del plan, con opciones por comida.
- Bloque post-entreno cuando se selecciona un día de entrenamiento.
- Rutina de 5 días con ejercicios, series, RIR/técnicas y carga de referencia.
- Registro de gemelos, abdominales y cardio.
- Rachas de dieta, entrenamientos y días perfectos.
- Calendario de abril de 2026.
- Guardado automático en `localStorage`.
- Exportación de copia de seguridad JSON.

## Publicarla en GitHub Pages

1. Crea un repositorio nuevo, por ejemplo `entreno-abril-2026`.
2. Sube `index.html` a la raíz del repositorio.
3. En GitHub abre **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`.
6. Guarda los cambios. GitHub te mostrará la URL pública cuando termine el despliegue.

No necesita servidor, base de datos ni instalación.
